# Analisa Pengaruh Kinerja Siswa SMA dalam Ujian

## Repository Outline
1. notebook.ipynb - Notebook yang berisi penjabaran problem statement dan dataset, kemudian dataset tersebut diolah, dibersihkan, dan di eksplorasi.
2. dataset.csv - berisi dataset yang akan diolah.



## Problem Background
Project ini menganalisis kinerja siswa dalam suatu ujian, di latar belakangi dengan adanya tingkat kemampuan siswa dalam melaksanakan ujian di tingkat SMA. Dapat di analisis korelasi antara latar belakang siswa SMA di Amerika Serikat


## Project Output
Hasil dari project ini berupa pembersihan data, dan kemudian di visualisasikan melalui dashboard Tableau.

## Data
Dataset ini berjudul 'Students Performance in Exams'. Datasest ini berisi 1.000 data siswa dengan 8 kolom. Kumpulan data ini berisi nilai yang diperoleh siswa dalam berbagai mata pelajaran. Data terinspirasi untuk memahami pengaruh latar belakang orang tua, persiapan ujian, dll terhadap kinerja siswa di Amerika Serikat. Sumber dataset ini berasal dari Kaggle.com.

## Method
project ini menggunakan metode Exploratory Data Analysis (EDA) dengan pendekatan statistik deskriptif dan inferensial.


## Stacks
Project ini menggunakan bahasa pemrograman python, pandas, dan memakai tools seperti seaborn, matplotlib, dan numpy.
